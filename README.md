## Лабораторная работа №3

**Тема:** Основы JavaScript  
**Каркас:** (https://github.com/teach-kirshdv/js-tasks)

**Задание:** реализовать 10 функций в `src/core.js`.

**Реализованные функции:**
- `isInteger(n)` — проверка целого числа через побитовые операторы
- `even()` — массив чётных чисел от 2 до 20
- `sumTo(n)` — сумма чисел до `n` через цикл
- `recSumTo(n)` — сумма чисел до `n` через рекурсию
- `factorial(n)` — факториал числа
- `isBinary(n)` — проверка степени двойки
- `fibonacci(n)` — N-е число Фибоначчи
- `getOperationFn(initialValue, operatorFn)` — замыкание для операций
- `sequence(start, step)` — генератор арифметической последовательности
- `deepEqual(a, b)` — глубокое сравнение объектов
